# Travel Booking Website

A modern, responsive travel booking website designed to provide users with a smooth experience for discovering hotels, exploring travel options, and viewing hotel details.

## 🚀Features

- **Home Page:** Attractive banners, recent searches, and best-selling hotels with carousel functionality.
- **Hotel Results Page:** Dynamic search information, hotel listings, filters, sorting, and view-more functionality.
- **Hotel Detail Page:** Detailed hotel information, image gallery, amenities, and booking-related interactions.
- **Interactive Header:** Navigation, user profile, language selector, notifications, and admin menu.
- **Cart Drawer:** Responsive side drawer for managing selected items.
- **Dynamic Footer:** Reusable footer across website pages.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Smooth Animations:** Modern transitions, hover effects, and interactive UI inspired by Airbnb.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Custom CSS
- Vanilla JavaScript (ES6 Modules)
- Google Fonts – Poppins
- Local Storage

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Run the Website

Use **VS Code Live Server** or another local development server.

Open `index.html` through the local server.

> Note: A local server is required because shared HTML components are loaded using JavaScript `fetch()`.
